# 高精度穷举匹配阶段交接计划

## 1. 文档目的

本文档是下一会话的实现起点。本阶段只实现一个“保召回的多尺度参考路径”：

- 召回率优先，目标是在定义的数据集和搜索域内不漏检；
- 严格最终验证，目标是在定义的负样本和干扰场景内不误检；
- 位置精度达到 `1/30` 像素；
- 角度、尺度达到明确的独立精度要求；
- 允许使用图像/模型金字塔进行多尺度搜索，但不考虑速度、内存、线程数、SIMD、GPU 或激进搜索剪枝。

本阶段的实现结果将作为下一阶段所有搜索优化的真值基线。任何优化后的搜索结果都必须与本阶段逐候选对比，不能只比较耗时。

## 2. 正确性边界

对任意图像、任意噪声和任意背景，不存在绝对的“零误检”保证。例如背景中存在与模板完全相同的物体时，算法无法仅凭图像区分实例来源。

本阶段采用以下可验收定义：在固定的图像形成条件、搜索范围、模型版本、遮挡规则和测试数据集上，要求：

1. 所有标注目标都被返回；
2. 负样本和标注中的非目标位置都不被返回；
3. 接受结果的位置误差不超过 `1/30` 像素；
4. 所有接受结果都能给出评分、覆盖率和误差上界。

无法满足严格条件的结果必须返回 `Ambiguous` 或直接拒绝，不能通过降低阈值强行接受。

## 3. 本阶段明确不做的内容

以下内容全部延期到“搜索优化阶段”：

- 高阈值多尺度剪枝；
- Canny 覆盖预筛选的性能化实现；
- Greediness 和启发式早停；
- 粗层模型点子集；
- Top-K 候选截断；
- 候选聚类导致的候选删除；
- 分支定界；
- 多线程、SIMD、GPU；
- 变换缓存、内存压缩和缓存优化；
- 面向吞吐量的 NMS 优化。

现有快速路径保持不变。新增路径允许使用金字塔，但每一层必须保留足够宽的候选集合，并且最终结果必须回到原图层使用完整模型重新验证。金字塔层不能成为唯一的正确性依据。

## 4. 精度和姿态定义

统一搜索四维姿态：

```text
P = (column, row, angle, scale)
```

模型点变换为：

```text
x = column + scale * (cos(angle) * px - sin(angle) * py)
y = row    + scale * (sin(angle) * px + cos(angle) * py)
```

第一版位置验收条件：

```text
abs(result.column - gt.column) <= 1/30
abs(result.row    - gt.row)    <= 1/30
```

同时记录欧氏位置误差。角度和尺度必须在配置中单独定义，例如 `0.01` 度和 `1e-4`，不能把角度或尺度误差隐藏在位置误差中。

为了保证位置精度，角度和尺度网格必须根据模型半径计算。令 `R` 为模型原点到最远模型点的距离，则量化误差应满足：

```text
translation_error
+ R * angle_error
+ R * scale_error
<= 1/60 pixel
```

建议参考实现的平移网格使用 `1/60` 像素，并使用更细的局部网格完成最终定位。

## 5. 高精度模型实现

涉及文件：

```text
include/openshape/core/types.hpp
include/openshape/model/shape_model.hpp
src/model/shape_model.cpp
```

### 5.1 新增高精度模型版本

现有模型点主要来自整数像素，且默认点间距和点数偏向粗匹配。新增独立的高精度模型版本，例如 `model_version = 2`，旧模型继续走旧路径，不允许在高精度路径中混用。

### 5.2 模型生成步骤

1. 模板统一灰度化、平滑和梯度计算；
2. 从梯度场提取轮廓候选，不只依赖二值 Canny 点；
3. 沿梯度法线方向对边缘峰值做亚像素拟合；
4. 得到亚像素轮廓坐标和法线方向；
5. 沿轮廓均匀采样，建议点间距不大于 `0.25` 像素，必要时使用 `0.1` 像素；
6. 保存坐标、法线、梯度强度、极性、权重和拟合残差；
7. 保存模型点所属的空间区域或轮廓分区；
8. 内部坐标和变换使用 `double`；
9. 保证整个轮廓都有覆盖，不能只保留最强的局部边缘。

### 5.3 模型分区

模型点应按轮廓弧长、ROI 网格或扇区划分为多个区域。每个区域记录点数、权重、包围盒和方向分布。最终验证时要求必要区域都获得支持，避免单条强边缘产生误检。

## 6. 连续场景边缘场和金字塔

涉及文件：

```text
include/openshape/edge/edge_engine.hpp
src/edge/edge_engine.cpp
```

高精度最终评分直接使用原始分辨率。金字塔只负责扩大搜索覆盖和逐层缩小候选位置范围，不能使用高阈值把可能的真实目标提前丢弃。场景预处理至少保存：

- 灰度图；
- `Gx/Gy`、梯度幅值和方向；
- 亚像素边缘位置；
- 连续边缘强度；
- 连续距离场；
- 边缘法线和极性；
- 有效区域 mask。

对每个边缘候选点，沿局部梯度法线采样多个位置，拟合梯度峰值或灰度跃迁，求出亚像素边缘中心。拟合残差过大的边缘点不得进入高精度场。

距离场不能只由整数 Canny mask 的距离变换生成；必须支持任意浮点坐标的连续距离、方向和强度采样。

### 6.1 金字塔构建

1. 使用与现有实现一致的 `pyrDown` 规则构建场景金字塔；
2. 为每个场景层生成同参数的连续边缘场；
3. 为每个模型层保存完整模型点，不做粗层点数缩减；
4. 坐标从粗层回到原图层时使用明确的层级缩放因子；
5. 最高精度只在 level 0 上验收，粗层只负责候选发现。

### 6.2 保召回的粗层阈值

每个粗层对平移、旋转、缩放三类姿态组合使用统一的宽松候选阈值 `level_min_score[level]`，不得直接使用最终 `min_score`。也就是说，粗匹配阶段不能只保留高分的平移候选、最佳角度或最佳尺度；只要三维姿态组合仍有可能在细层通过，就应尽量保留。初始策略建议：

```text
level_min_score[level] = max(0, min_score * 0.25)
```

如果该阈值在验证集上造成任何漏检，则降为 `0`，该层只做完整评分和候选记录，不按分数拒绝。各层可见点要求可以低于最终要求，但不能使用点子集、Greediness 或启发式早停。所有金字塔层都允许使用第 8.3 节定义的安全提前终止。粗层阈值只用于候选发现，不用于最终接受；最终准确率、误检控制和 1/30 像素精度由 level 0 完整复核决定。

粗层不允许 Top-K 截断、`coarse_candidate_limit` 截断、峰值聚类删除候选、按经验固定保留比例或只保留最强模型点。候选数量很大是本阶段可以接受的代价。

## 7. 高精度评分函数

新增独立评分入口，不改变旧 `score_pose` 的历史语义。对每个模型点计算：

- 到场景边缘的距离；
- 模型法线和场景法线的相似度；
- 边缘强度；
- 极性一致性；
- 是否越界；
- 所属区域是否得到支持。

建议的单点评分结构为：

```text
point_score =
    distance_score
    * orientation_score
    * magnitude_score
    * polarity_score
```

整体得分必须以全部模型点作为分母：

```text
score = sum(all_model_points(w_i * point_score_i)) / sum(all_model_points(w_i))
```

不能只对命中点归一化，否则部分模型越界或局部轮廓匹配时分数会虚高。

评分结果还要输出总模型点数、有效点数和有效权重比例、每个区域覆盖率、平均和最大边缘距离、方向一致率、极性一致率及评分残差。

## 8. 金字塔多尺度穷举搜索器

建议新增：

```text
include/openshape/matcher/exhaustive_matcher.hpp
src/matcher/exhaustive_matcher.cpp
```

### 8.1 搜索域和网格

根据 `search_roi`、图像尺寸、模板包围盒、角度范围和尺度范围确定有限的四维搜索域。无遮挡模式下，可要求变换后的模型完全落入图像；若允许越界，则由可见率规则处理。

角度、尺度、平移均使用整数索引计算：

```text
value = start + index * step
```

禁止通过浮点数反复累加步长，保证结果可复现。建议固定遍历顺序为：

```text
scale -> angle -> row -> column
```

### 8.2 从粗到细的完整候选传播

搜索从最粗层开始，到 level 0 结束。每一层都使用该层完整模型点和该层连续边缘场。

每一层都必须对旋转和缩放执行网格穷举。允许继承上一层的候选角度和尺度作为搜索中心，但不能只使用上一层的最佳值，也不能把窗口设置得过窄：

- 粗层通常覆盖完整 `angle_start/angle_extent` 和 `scale_min/scale_max`；
- 细层可以围绕上一层的多个候选中心搜索；
- 每个中心都必须使用宽角度窗口和宽尺度窗口进行穷举；
- 窗口至少覆盖上一层网格误差、金字塔缩放误差、评分噪声和模型量化误差；
- 如果无法证明窗口足够大，则扩大窗口，必要时回退到完整角度/尺度范围；
- 每个窗口内的 `(angle, scale)` 组合都必须参与该层的平移搜索。

上一层候选不能只保留一个“最佳姿态”。在本阶段应保留所有通过低层阈值的候选，或至少保留足够宽的候选集合；禁止使用过小的 Top-K、峰值聚类或严格的最佳值继承规则。

在平移维度上，上一层候选可以用于生成细化窗口，但只有在能够证明窗口覆盖所有量化误差、旋转误差和尺度误差传播范围时才允许缩小。无法证明时，该层平移也必须覆盖完整搜索 ROI。

因此，每一层的基本搜索结构都是：

```text
for every inherited candidate window or full range of scale at this level
  for every inherited candidate window or full range of angle at this level
    for every valid translation (full ROI or proven-safe window)
      evaluate the complete model
```

进入下一层时，上一层候选用于提供平移、角度和尺度的搜索中心，但不能把搜索收缩成单点或极窄窗口。继续使用宽松阈值，直到 level 0。

最终 level 0 必须使用完整模型和原图连续场重新验证。参考实现优先保留一次完整 level 0 确认性穷举，以便获得不依赖金字塔阈值的真值结果。

### 8.3 姿态遍历

对每一个姿态：

1. 变换全部高精度模型点；
2. 对全部模型点进行连续场景采样；
3. 计算完整评分；
4. 计算有效率、区域覆盖率、方向和极性指标；
5. 保存结果或写入评分体。

本路径严禁任何激进提前排除：不做启发式早停、模型点减少、候选截断或任意层失败回溯。所有金字塔层都允许使用安全提前终止，但必须满足以下条件：

1. 当前姿态已经处理的点给出严格的可达分数上界；
2. 即使剩余所有模型点得到理论最大分数，仍低于当前层的宽松阈值；
3. 或者当前姿态已经达到当前层候选记录阈值，此时可以停止继续累加，并将其标记为“待完整复核候选”；
4. 安全终止不能删除一个可能通过当前层阈值的姿态，只能减少当前评分计算；通过当前层的候选仍需进入下一层或 level 0 的完整评分；
5. level 0 最终验证禁止提前接受，必须完整计算全部模型点和全部统计指标。

每个金字塔层允许使用该层对应的低 `level_min_score[level]` 作为平移、旋转、缩放组合的候选记录阈值，但一旦验证集出现漏检，该层阈值必须降为 `0`。安全终止必须记录所在层、终止原因、已评估点数和理论分数上界，便于回归测试审计。

安全拒绝的上界计算必须使用当前评分函数的真实归一化方式。设：

```text
S_done       = 已处理模型点的加权得分
W_done       = 已处理模型点的总权重
W_remaining  = 未处理模型点的总权重
W_total      = W_done + W_remaining
```

在单极性模式下，未处理点的单点得分最大为 `1`，因此：

```text
score_upper_bound = (S_done + W_remaining) / W_total
```

如果：

```text
score_upper_bound < current_level_threshold
```

则当前姿态不可能达到当前层阈值，可以立即拒绝，不再计算剩余模型点。

可见点数量也可以使用同样安全的上界：

```text
visible_upper_bound = valid_done + remaining_point_count
```

如果 `visible_upper_bound < required_visible_count`，可以立即拒绝。

`GlobalEither` 模式必须分别维护同极性和反极性的 `S_done`，分别计算两个上界后取较大值；不能只根据当前较大的部分得分直接终止。所有权重、方向、距离和极性惩罚都必须纳入上界定义，不能使用比评分函数更乐观或更悲观的经验常数。

安全提前终止只允许产生“确定拒绝”或“待完整复核候选”，不能把部分评分直接作为最终分数返回。实现时应在 `SearchStats` 中记录：终止次数、按分数上界终止次数、按可见点上界终止次数、终止时已处理点数和终止时上界。

如果评分体过大，可以按固定块执行，但块划分只能解决存储问题，不能改变完整遍历语义。每个块完成后保留全部局部峰值和所有超过宽松阈值的候选，块间再统一合并。

## 9. 局部峰值和精度细化

穷举结束后，在四维邻域中提取所有局部极大值，不限制候选数量，不提前 NMS。

对每个峰值：

1. 建立局部姿态区域；
2. 将平移网格细化到 `1/120` 或更细；
3. 按模型半径同步细化角度和尺度；
4. 重新对局部区域内所有姿态完整评分；
5. 直到当前姿态单元造成的最大几何误差小于 `1/60` 像素；
6. 输出局部最高分姿态和误差上界。

现有连续优化器可以辅助寻找峰值，但不能作为唯一精度依据。优化结果必须和局部穷举结果比较，较差时回退到穷举结果。

## 10. 严格最终验证

所有候选必须使用完整高精度模型、原始分辨率场景和完整评分重新验证。至少同时满足：

```text
score >= T_score
visible_fraction >= T_visible
必要区域覆盖率 >= T_region
平均边缘距离 <= T_distance
方向一致率 >= T_orientation
极性约束通过
```

第一版为保证零误检，建议 `T_visible = 1.0`，后续如需遮挡再单独扩展。结果分为 `Accepted`、`Rejected`、`Ambiguous`；无法证明满足精度或阈值的候选不得作为正式匹配返回。

## 11. 实例结果和 NMS

本阶段以召回优先，NMS 只放在最终严格验证之后。默认行为：返回所有通过验证的局部峰值，不限制 `num_matches`，不使用 IoU 阈值提前删除候选，只合并姿态距离极近且明确属于同一评分峰的重复结果。两个真实目标的合并规则留给后续业务策略。

## 12. 测试和验收

建议新增：

```text
tests/exhaustive_regression_tests.cpp
tests/subpixel_accuracy_tests.cpp
tests/false_positive_tests.cpp
```

合成数据应随机覆盖任意小数平移、旋转、尺度、模糊、噪声、对比度、极性和边界位置，并保存真实姿态。验收目标为：召回率 100%、误检数 0、位置最大误差不超过 `1/30` 像素。

漏检测试应覆盖极端角度、极限尺度、低对比度、多目标、重叠目标、反极性和允许的遮挡场景。误检测试应覆盖空白图、噪声图、单条强边缘、局部相似轮廓、重复纹理、旋转对称图形、缺失轮廓和相似但不同物体。

还要验证重复运行、不同分块方式、不同编译优化级别、`float/double` 对比下的结果稳定性。
