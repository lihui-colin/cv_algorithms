# CV Algorithms

Computer vision algorithm experiments and reproducible prototypes.

## Projects

### Shape Matching

`shape_match` is a Python + OpenCV prototype for HALCON-like shape-based
matching. The first milestone covers gradient-orientation models, image
pyramids, rotation candidates, coarse-to-fine search, and multi-object NMS.

- [Project README](shape_match/README.md)
- [Implementation plan](shape_match/plan.md)

## Repository Status

The repository is currently in the planning and scaffolding stage. The
algorithm scope, validation strategy, and follow-up milestones are documented
in the shape-matching project plan.
