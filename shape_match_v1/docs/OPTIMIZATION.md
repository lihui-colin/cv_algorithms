# 优化方向与优先级

当前先提供完整可运行的数值与接口基线。性能以 `results/timing.json` 和 `results/benchmark.json` 为准。10 ms 是目标，尚未实现。

## 1. 先根据剖析决定工作顺序

`GetSearchDiagnostics` 分解金字塔、粗搜、跟踪和精定位时间，另记录评估位姿数量与候选数量。使用 `performance_bench` 在同进程、同图、已训练模型下预热一次，再重复搜索，避免把启动、PNG 解码或建模误认为搜索时间。

固定 CPU、线程数、模板大小、模板数量、角度/尺度区间和目标数量后才能比较。部署 CPU 未指定，当前虚拟执行环境不能代表用户目标 CPU。

## 2. CPU 性能优化

| 优先级 | 修改位置 | 具体实现方向 | 必须保留的验证 |
|---|---|---|---|
| P0 | EvaluatePose / SearchCoarsestLevel | 对每个角度/尺度预计算相对位置和旋转法线；扫描平移时只加偏移 | 全部候选得分与标量基线误差 |
| P0 | 搜索特征布局 | 从 EdgeFeature AoS 转成 x/y/nx/ny 连续 SoA 数组；按访问顺序缓存 | 同一输入检出/排序是否变化 |
| P0 | EvaluatePose | AVX2/AVX-512/NEON 分别实现距离与方向批量计算，保留 portable 回退 | 边界点、负坐标、尾部不足向量宽度 |
| P0 | 高斯距离衰减 | 精确 exp 与插值 LUT 或多项式实现作误差/耗时对比 | 得分阈值附近不能凭经验宣称无影响 |
| P1 | 粗层搜索 | 预排序有辨识度的特征，提高安全上界提前退出率 | 保持得分定义，测试遮挡目标 |
| P1 | 候选管理 | 空间分桶降低 MergeCandidates 的二次比较；按块处理热区域 | 相邻/重叠目标的召回 |
| P1 | FindGenericShapeModel | 线程池并行模型或候选精定位，图像金字塔只读共享 | 并发可重入、稳定排序与线程数扩展 |
| P1 | 图像内存 | 缓冲池复用金字塔、梯度、标签和候选向量 | 分辨率变化、并发请求之间不串数据 |
| P2 | BuildEdgeField | 精确线性时间 EDT 与当前近似标签传播对比 | 对应点切换、距离精度、运行时 |
| P2 | MinimumRectangle | 旋转卡壳降低凸包边枚举复杂度 | 矩形角点顺序及重叠面积 |

不要通过固定只搜索样图的上下两条带达到 10 ms，因为任务要求全图搜索。可以增加可选的目标候选生成器，但必须同时保留完整搜索路径并报告其漏检风险。

候选束、粗层阈值和减少金字塔层数不是无损优化。提速版本必须比较完整检出集合及精度，而不只是某一张图耗时。

## 3. 亚像素精度优化

| 优先级 | 修改位置 | 具体实现方向 | 判定指标 |
|---|---|---|---|
| P0 | ExtractSubpixelContours | 测试不同方向/相位下的边缘定位偏差，比较二次峰、导数高斯和模糊阶跃拟合 | 各相位 bias、RMSE、P95 |
| P0 | BuildCorrespondences | 法线剖面搜索与当前最近边缘点比较；减少角点处切换 | 角点/曲率/遮挡分组误差 |
| P0 | 模板建模 | 模板和搜索图的成像模糊不同时调整边缘观测模型 | PSF 不匹配下的误差 |
| P1 | BuildNormalEquations | 引入噪声估计权重，防止高密度轮廓片段过度支配 | 圆孔/外轮廓贡献与系统偏差 |
| P1 | SolvePoseIncrement | 使用归一化参数和特征值/条件数分析，显式检测不可观测自由度 | 对称、近直线、局部遮挡场景 |
| P1 | RefineInstance | 研究鲁棒损失与异常点剔除；与当前普通最小二乘分支对照 | 真实异常点下收益，无噪声下是否引入偏差 |
| P2 | 标定与成像 | 镜头畸变、光照漂移、机械位移真值和温漂误差分离 | 可溯源实拍位移误差 |

不能通过增加输出小数位、缩小停止阈值或单纯增加迭代次数证明 1/30 px。也不能把同源模板自匹配、或 HALCON 与本实现之间的差异直接视为绝对精度。

## 4. HALCON 兼容性优化

1. 在用户实际 HALCON patch 版本运行算子级差分用例，首先检查非零旋转、非单位尺度及原点偏移下的 row/column/hom_mat_2d。
2. 查询训练前后全部支持参数；对 auto 的设置值和实际值分别比较。
3. 验证 num_matches 的中间层筛选效应、strict_boundaries 顺序和同分结果排序。
4. 扩展每模型 Domain 的图像对象元组；随后按需求实现各向异性尺度。
5. 若需要 score 数值接近，单独研究模型特征、遮挡归一化及评分，而不是对 score 做样图拟合校准。
6. HALCON 的内部实现未公开，不承诺通过修改几个常数就能取得逐位一致结果。

## 5. 推荐优化门槛

任何新优化必须先通过现有契约回归和 7 目标样图验证，再比较独立合成集，最后测耗时。若有精度/召回下降，要保留开关、报告收益和损失，不能静默替换默认基线。
