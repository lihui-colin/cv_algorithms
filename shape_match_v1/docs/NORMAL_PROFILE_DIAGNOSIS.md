# 法向峰定位对照

2026-09-15。目标是缩小最终位姿与 HALCON 的差异。共完成 32 组对照，但没有通过精度验收，生产算法和默认参数未修改。
逐目标位置、角度、尺度误差及 GT 文件校验值见 [测量数据](normal_profile_measurements.json)。

## 实验边界

所有实验从同一组基线自动检出的最终位姿开始，不使用 GT 初始化。严格说是固定基线精定位结果，而不是尚未精定位的粗层候选。
保留全部基线实例、不重新执行 NMS，所以 7 个输出不等于独立召回验证。
探针只覆盖当前 use_polarity、自由等比尺度样例，不是通用生产 API。

控制变量：中心差分/高斯导数 sigma=0.8；法向搜索半径 1/2px；最近有效局部峰/最强有效局部峰；模型法线/场景法线残差；原模板/重定位模板。共 2×2×2×2×2=32 组。
采用梯度双线性采样、0.25px 剖面步长和三点二次峰插值，响应门限 3，方向点积门限 0.65。
模板重定位使用相同梯度和峰插值方法，固定半径 1px、最近峰选择，保持原点和点数不变；未找到峰的点仍保留原值。
求解为归一化四自由度阻尼迭代、步长限制及重新关联后的缺失点惩罚验收，最多 30 轮。
新求解器不包含生产路径的所有回退语义，基线到新路径的变化不能只归因于一个因素；应优先解释新路径内部的单项对照。

## 结果

| 设置 | 位置 RMSE px | 最大误差 px |
|---|---:|---:|
| 原默认 | 0.300350 | 0.579015 |
| 高斯、半径2、最近峰、场景法线、原模板 | 0.275818 | 0.565532 |
| 高斯、半径2、最强峰、场景法线、原模板 | 0.278224 | 0.565532 |
| 高斯、半径2、最近峰、模型法线、原模板 | 0.279976 | 0.579931 |
| 高斯、半径2、最近峰、场景法线、重定位模板 | 0.287763 | 0.632030 |

原模板的较好方案使自匹配 nut/ring 的位置误差增加到约 0.052/0.019px；统一两端定位后降为约 0.00317/0.00886px。
但在同一重定位模板设置下，小 nut (#3) 从 0.46073 降到 0.38017px，中等 nut (#6) 从 0.22557 降到 0.07294px，大 nut (#4) 反而从 0.57902 升到 0.63203px。
不能按目标挑选不同实验的最优结果拼接输出。所有设置均未达到 RMSE≤0.10px、最大≤0.20px。
本轮最好 RMSE 仍高于此前可选 contour 模式的 0.23323px，不是工程整体最优结果。

## 判断

采样与峰选择确实影响最终位姿，但最近峰/最强峰差异不足以解释全部偏差。
模板重定位改善自匹配却加重大 nut 的偏差，说明尚未找到统一复现 HALCON 输出的方案。
这些只是受控实验结论，不是已证实的 HALCON 内部机制。
下一步应检查大 nut 内外轮廓的有效对应覆盖、法向残差及对平移/角度/尺度更新的贡献，不根据 GT 直接选择边段或权重。

## 复现

```bash
cd shape_match_v1
bash scripts/build.sh
SHAPE_MATCH_NUM_THREADS=8 ./build/halcon_parameter_probe data results-profile-new
python3 scripts/compare_gt.py results-profile-new/profile_gaussian_r2_nearest_scene.csv \
  --reference data/reference/matching_results.csv --max-rmse 0.1 --max-error 0.2
```

输出目录必须不存在。最后一条精度验收预期失败。探针成功退出只表示实验执行成功。
实现位于 `tests/normal_profile_probe.hpp`，由已有参数探针调用，不影响 `match_sample`。
新增观测单测验证最近峰/最强峰分离、法向位置、单位法线、边界、极性与无梯度输入。
