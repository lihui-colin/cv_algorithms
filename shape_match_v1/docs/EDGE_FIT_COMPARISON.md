# 匹配位姿下 pattern 与原图亚像素边缘的贴合程度

## 结论

当前图像中，复现版比 HALCON **普通 least_squares** 更贴合外轮廓；
普通 least_squares 对内轮廓整体更贴合。不能简单称某一方“全面更精确”。
HALCON **very_high** 的外轮廓残差又略低于复现版，模式必须明确。
这里测量轮廓与图像的贴合，不是具有物理真值的位姿精度。

## 如何避免用自身优化目标给自身打分

- 两方使用同一份 HALCON 导出的 pattern 轮廓点，不使用复现版内部模型点。
- 生产匹配结果重新运行生成，检测阶段不读取参考位姿。
- 独立 Python/SciPy 测量，不调用复现版的场景边缘、最近邻或优化器。
- 对每个对应模板点，取两方投影位置的中点作为共享观测锚点；以共享局部轮廓法线采样原图。
- Gaussian 导数场沿法线每 0.05px 采样，在 ±2.5px 内取最近的梯度幅值局部峰，
  再以三点抛物线定位峰值。方向一致度至少 0.8、响应至少 5，边界点排除。
- 同一次比较中，双方使用**相同观测点、法线和有效点集合**；计算投影轮廓到观测点的法向距离。
- 分别检查 sigma=0.6、1.0、1.4，避免只选择对某一方有利的平滑参数。

该方法仍然是边缘估计器，不是精确真值。梯度幅值忽略极性，邻近纹理或双边缘可能
产生错误峰，尤其在内轮廓；应结合覆盖率，不能把这些峰全称为真实对应边缘。
所有统计为点加权 RMSE，不是七个目标中心的 RMSE，也不是完整二维点到点误差。

## 普通 least_squares：总体与内外轮廓

两份模型共投影 2870 个不重复闭合端点的轮廓点，其中外轮廓 1954、内轮廓 916。
数值单位 px；同一行的两方有效支持相同。

| sigma | 轮廓 | 有效/总数 | HALCON RMSE | 复现版 RMSE |
|---|---|---:|---:|---:|
| 0.6 | 外轮廓 | 1954/1954 | 0.4552 | **0.3020** |
| 0.6 | 内轮廓 | 693/916 | **0.9853** | 1.1301 |
| 1.0 | 外轮廓 | 1954/1954 | 0.4658 | **0.3166** |
| 1.0 | 内轮廓 | 655/916 | **1.0064** | 1.1144 |
| 1.4 | 外轮廓 | 1954/1954 | 0.4841 | **0.3459** |
| 1.4 | 内轮廓 | 634/916 | **1.0067** | 1.1172 |

sigma=1 时全部有效点 2609/2870，总体 HALCON 0.6456px、复现版 0.6220px。
这个小幅总体优势掩盖了内外轮廓的相反趋势。

### 外轮廓逐目标（sigma=1）

| 参考 index / 目标 | HALCON | 复现版 |
|---|---:|---:|
| 0 / 原尺寸 nut | 0.0340 | 0.0340 |
| 1 / 原尺寸 ring | 0.0355 | 0.0355 |
| 2 / 缩小 ring | **0.2720** | 0.3287 |
| 3 / 缩小 nut | 0.3810 | **0.1971** |
| 4 / 放大 nut | 0.4980 | **0.2849** |
| 5 / 放大 ring | 0.9402 | **0.6210** |
| 6 / 中等 nut | 0.2024 | **0.0838** |

因此并非所有目标都由复现版胜出。原尺寸两个目标接近，差别不足以支持实际精度优劣判断。

## 与其他 HALCON 模式的交叉检查

sigma=1，仍在每对比较中共享观测点：

| HALCON 模式 | 外轮廓 HALCON / 复现 | 内轮廓 HALCON / 复现 | 内轮廓有效数 |
|---|---:|---:|---:|
| least_squares | 0.4658 / 0.3166 | 1.0064 / 1.1144 | 655 |
| least_squares_high | 0.3372 / 0.3159 | 1.0170 / 1.0422 | 638 |
| least_squares_very_high | **0.3040** / 0.3159 | 1.0053 / **0.9760** | 623 |

不同模式的共享锚点会变，故有效点集合也会变；应比较**同一行内**的双方，
不能直接把跨行内轮廓分数当作统一排行榜。very_high 外轮廓的轻微优势在三个 sigma 下均存在。

## 对当前对齐任务的含义

约 0.3px 的 HALCON 位姿差异不能直接解释为“复现版真实定位差了 0.3px”。
当前复现版在普通 least_squares 的几个偏差较大目标上，反而有更低的外轮廓法向残差。
数据支持内外轮廓的贴合存在取舍，但尚不足以断定 HALCON 使用了怎样的权重或停止策略。
若要判断绝对位姿准确性，还需要已知变换的独立图像或标定真值。
