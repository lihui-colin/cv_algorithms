# 测试规范与验收范围

## 1. 已运行的测试

`tests/test_match.cpp` 包含带类型断言和实际搜索的回归，断言数受轮廓点数影响，不能把 184 个断言说成 184 个独立场景。

- HTuple 类型、索引越界、禁止整数冒充句柄。
- 新模型状态、未训练搜索报错。
- 未支持参数报错、非法参数事务回滚。
- 建模参数与搜索参数的训练状态差异。
- 一个非对称目标的亚像素位置。
- all/best/index/identifier/handle 组合、去重和排序。
- 实例轮廓与 hom_mat_2d 的像素/边缘中心转换一致性。
- 搜索 Domain 排除目标中心；常量负样本返回零目标。
- 用户原点偏移按位姿正确变换。
- 全图两个同类实例以及 num_matches 数量限制。
- none、interpolation、high 最小二乘模式可执行。
- 全局与局部反极性场景。
- 模型标识重复检测。
- 清理句柄后别名失效，已有匹配结果仍可读取。

`match_sample` 使用真实上传模板和原图。`scripts/report.py` 使用类别和 3 px 位置门限将结果与已知 7 个目标一对一关联。分类/检出门限只是该示例的回归条件，不是定位精度标准。

## 2. 独立精度实验

`accuracy_bench` 运行 30 个无噪声案例：20 个平移相位、10 个角度/尺度组合。模板图和搜索图分别由连续几何生成；使用亚像素 8×8 积分近似，不对同一整数位图反复 warp。

主指标为二维位置误差 RMSE，另报告 P95 和最大值。测试是单种非对称形状、小范围姿态变化，尚不覆盖相机成像和复杂纹理；不足以形成通用工业精度认证。结果以 `results/accuracy.csv` 和 `results/VALIDATION.md` 为准。

同图自匹配得分 1 只用于坐标和一致性检查，不参与独立精度证据。HALCON 的参考结果不是真值。

## 3. 内存检查

用 AddressSanitizer 与 UndefinedBehaviorSanitizer 编译，运行实际契约测试。单独构建目录避免覆盖 release 二进制；日志随包提供。成功不表示已经证明所有输入无内存问题。

本次环境在 ptrace 下执行，LeakSanitizer 报运行环境不支持；原始日志保留在 `results/leak_sanitizer_environment.log`。随后使用 `ASAN_OPTIONS=detect_leaks=0 UBSAN_OPTIONS=halt_on_error=1` 运行，地址越界与未定义行为检查通过。未声称通过泄漏检测；目标机器应重新开启 detect_leaks=1 验证。

## 4. 性能实验

```bash
./build/performance_bench 5 results/benchmark.json
```

固定样例 640×480、两模板、所有 7 个目标、全图、默认 min_score=0.5、最高最小二乘模式。先预热 20 次，再用 `performance_bench 500 /tmp/benchmark.json` 测同进程 500 次，排除训练和 I/O，计入每帧图像预处理。输出每次时间、中位数、P95、最小值、最大值及分阶段 CSV。默认最多 4 线程；验收目标 P95 ≤20ms，当前尚未达标，见 [速度优化记录](SPEED_OPTIMIZATION.md)。

当前核心单线程。10 ms 的最终验收还需用户指定的 CPU/线程数/目标负载和至少足够多次运行以统计 P95；本次 5 次实验仅用于基线。

## 5. 下一轮必须扩展的实验

| 场景 | 必须记录 |
|---|---|
| 噪声与模糊 | 噪声幅度、PSF、对比度、检出率和精度分组 |
| 旋转全周期、尺度大范围 | 对称等价角度、采样密度与漏检 |
| 相邻目标、遮挡、干扰纹理 | Recall、Precision、重复数 |
| 边缘/域边界 | 部分越界、中心恰好在边界、不同金字塔层 |
| 数百实例 | 候选束上限导致的召回变化 |
| HALCON 差分 | patch 版本、默认/显式参数、矩阵和例外行为 |
| 实拍位移真值 | 标定、装置分辨率、位移不确定度、温漂 |

本工程所有运行数据都应由可执行程序重新生成；不要将示例期望数量或坐标写进匹配器实现。
