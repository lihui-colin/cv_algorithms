# 当前输出与样图 GT 的误差

后续旧版对照、收敛性和对应点诊断见 [REFINEMENT_DIAGNOSIS.md](REFINEMENT_DIAGNOSIS.md)。

输入为默认 640×480 样图及 ring/nut 两个模板，使用完整默认搜索范围。
参考文件：`data/reference/matching_results.csv`。此表记录本次代码精简后的结果；
重构前后匹配 CSV、轮廓 JSON 和独立合成集数值逐项一致（计时除外）。

## 对齐及计算方式

- GT 的 model 列全部为 nut。依据 `data/PROVENANCE.md` 中的历史标签说明，
  比较时将参考序号 1、2、5 视为 ring，其余视为 nut，原文件不修改。
- 同类别按位置最近邻一对一关联，3px 门限；7 个参考目标全部关联，无多余结果。
  输出顺序按得分排列，与 GT 顺序不同，不能直接逐行相减。
- 带符号差值均为输出减 GT；位置误差为 sqrt(Δrow² + Δcolumn²)。
- 角度依现有报告规则按 ring 45°、nut 60° 对称周期折算。本次所有原始角度差
  已在对应半周期内，折算不改变数值。
- 尺度相对误差为 100 × (输出尺度 / GT 尺度 − 1)。两份 CSV 的
  scale_row 和 scale_column 均相等，因此两轴尺度误差相同。
